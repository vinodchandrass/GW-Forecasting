# Paper A upload scope (preliminary static audit)

The investigator-supplied `GW_PaperA_Review.zip` contains five Python scripts and associated READMEs/reports. The five Python scripts passed syntax parsing and a limited embedded-secret pattern scan. **This is not a full reproducibility verification.** The scripts require external local inputs that are deliberately not redistributed.

Candidate original experiment modules:
- `GW_Common_Protocol_Experiment/run.py`
- `GW_Common_Unseen_Station/run.py`
- `GW_Targeted_Final_Diagnostics/run.py`
- `Maharashtra_Completion/run.py`
- `GW_Five_State_Consolidation/run.py` (evidence consolidation, not a new experiment)

Do not upload source datasets, processed station-month tables, manuscripts, figures/maps, third-party material, or unverified intermediate files. Reports must be labeled as outputs from the original local execution, not as independently reproduced results. The final release requires verification of source-to-result integrity and investigator approval.
